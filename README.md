# 简历智诊（resume-zhizhen）

求职进度管理与面试准备微信小程序。投递管得住、简历看得清、面试练得熟 —— 把校招这半年，变成一张看得见进度的清单。

- 纯微信原生小程序 + 微信云开发，无任何第三方 UI 依赖（TDesign 已 vendor 内置）
- **不调用任何生成式 AI**：自查、比对、解析均由本地规则引擎完成
- 数据**默认存本机**，仅本人可见，隐私最小化

---

## 功能

| 模块 | 说明 |
|---|---|
| 求职看板 | 投递记录 CRUD、状态流转、漏斗统计、面试日程提醒、简历版本管理、搜索归档 |
| 简历自查 | 5 大维度 24 项预设检查 + 自动预检 + 加权规则评分（非 AI 生成） |
| 岗位比对 | 简历 vs JD 关键词覆盖率（本地词库匹配） |
| 简历解析 | 一键提取联系方式 / 教育 / 技能 / 经历（规则提取） |
| 面试题库 | 100+ 高频题 · 行为面 / 后端 / 前端 / 算法 / HR · 搜索与收藏 |
| 面试练习室 | 抽题 + 计时 + 文字作答 + 对照参考答案 + 三维度自评 |
| 刷题模式 | 顺序 / 随机 / 错题重刷，正确率统计 |
| 面试复盘 | 结构化模板记录每次面试 |
| 更多工具 | 求职 Checklist、学习路径、自我介绍模板、Offer 对比、待办、投递时间线、校招倒计时、数据统计、备份恢复 |

> 面向用户的产品介绍见 [docs/14-产品简介（面向用户）.md](docs/14-产品简介（面向用户）.md)。

## 技术栈

- 前端：微信小程序原生（WXML / WXSS / JS），无构建步骤
- UI：TDesign 微信小程序组件库（vendor 化内置，不跑「构建 npm」）
- 后端：微信云开发（云函数 / 云存储）
- 测试：Vitest（单元测试覆盖纯业务逻辑与云函数）
- CI：GitHub Actions（静态守卫 / 密钥扫描 / 单测 / 云函数打包体积门禁）

## 项目结构

```
├─ miniprogram/            # 小程序前端
│  ├─ pages/               # Tab 页（首页/面试/看板/我的）
│  ├─ package-tools/       # 分包：工具页（自查/比对/题库/练习等）
│  ├─ services/            # 业务逻辑层（纯函数，可单测）
│  ├─ data/                # 题库等静态数据
│  ├─ vendor/              # TDesign 组件（内置，不联网）
│  └─ config.js            # 前端常量（云环境 ID 在此配置）
├─ cloud/functions/        # 云函数
│  ├─ login/               # 静默登录
│  ├─ parse-resume/        # 简历附件解析（PDF/DOCX/TXT），解析后即删
│  └─ reminder/            # 可选订阅消息日程提醒
├─ scripts/                # 工程脚本（建库/打包/质量门禁）
├─ tests/  cloud/tests/    # Vitest 单测
└─ docs/                   # 文档（产品简介、隐私说明）
```

## 快速开始

### 1. 准备

1. 注册[微信小程序](https://mp.weixin.qq.com/)账号，拿到 **AppID**
2. 开通**微信云开发**，创建环境，记下**环境 ID**

### 2. 配置

```bash
# 前端：填入你自己的云环境 ID
# 编辑 miniprogram/config.js → CLOUD_ENV_ID

# 工程脚本用到的凭据（可选，本地建库用）
cp config/secrets.example.json config/secrets.local.json
# 然后填入你的 appid / appSecret / cloudEnvId
```

`project.config.json` 中的 `appid` 已置为占位 `touristappid`，用微信开发者工具打开后改为你自己的。

### 3. 运行

用**微信开发者工具**导入项目根目录：

- `miniprogramRoot` 与 `cloudfunctionRoot` 已在 `project.config.json` 配好
- 云函数在工具中右键「上传并部署：云端安装依赖」

### 4. 测试

```bash
npm install
npm test           # 单元测试
npm run check      # 完整质量门禁（语法 + AI 残留 + 密钥扫描 + 测试）
```

## 隐私

- 数据默认仅存本机；投递记录仅在用户主动开启「云提醒」后才上传时间字段
- 简历附件仅用于即时解析，云函数解析完成后立即删除云端文件
- 不收集手机号 / 通讯录 / 位置 / 昵称头像
- 详见 [docs/15-用户隐私保护指引补充说明.txt](docs/15-用户隐私保护指引补充说明.txt)
