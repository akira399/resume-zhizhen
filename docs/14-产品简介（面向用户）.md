## 三、长版（用于介绍页 / 大赛材料）

### 求职这件事，别再靠脑子和 Excel 硬记

你有没有过这样的经历——

- 海投了几十家，面试电话来了，却想不起这是哪家公司、投的什么岗
- 笔试、面试时间散落在短信和群聊里，一忙就错过
- 简历改来改去，不知道到底差在哪
- 面试前想练两句，翻了半天面经，还是不知道从哪开口

**简历智诊**把求职拆成「记录、自查、比对、练习」四件事，全部装进一个工具，
每一步都有清单、有进度、有结果。

---

### ① 求职看板：每一笔投递都有去处

把每一家投递记下来：公司、岗位、渠道（内推 / 官网 / 招聘平台）、用的哪版简历、现在到哪一步。

- **投递漏斗**：投递 → 笔试 → 面试 → Offer，一眼看清自己卡在哪一环
- **近期日程**：笔试 / 面试时间自动置顶，今天的安排高亮提醒
- **简历版本管理**：V1 通用版、V3 量化版…哪一版转化好，数据说了算
- **搜索与归档**：记录多了也找得到；结束后归档，保持看板清爽
- 第一次用？**一键填充演示数据**，先看完整形态再录自己的

---

### ② 简历自查：24 项逐条过一遍，差在哪立刻知道

粘贴简历正文（支持 PDF / Word / TXT **从文件导入**），点击「开始自查」：

- 系统先做**自动预检**：联系方式、数字量化、行动动词等能自动判断的项目先标好
- 再按 **5 大维度 24 项**逐条确认：结构与完整性 / STAR 表达 / 量化成果 / 行动动词 / 格式规范
- 实时得到 **0-100 加权得分**，每一项都有对应的改进建议，不是笼统一句「不够好」
- 没有简历？先点示例试一遍，不费任何事

---

### ③ 岗位比对：投之前，先看这份简历合不合

选好岗位方向（后端 / 前端 / 算法 / 数据 / 产品 / 运营…），把目标岗位的 JD 和你的简历放一起：

- 输出 **关键词覆盖率**（如 68%）
- ✅ 已覆盖的技能、❌ 缺失的关键词（按 JD 出现频次排序）一目了然
- 同一份简历投不同岗位，先跑一次比对，再决定要不要针对性微调

---

### ④ 简历解析：联系方式 / 技能 / 经历一键提取

粘贴简历，自动结构化提取**电话、邮箱、GitHub、教育背景、专业技能标签、经历要点**，一键复制摘要。
做网申、整理投递材料时的效率小工具。

---

### ⑤ 面试题库 + 练习室：练到说得顺为止

- **100+ 道高频题**：行为面 / 后端 / 前端 / 算法 / HR 五大类，可搜索，候场时随手翻
- **面试练习室**：抽题 → 限时作答 → 对照参考答案 → 三维度自评打分，
  逼自己像在真面试里一样组织语言
- **刷题模式**：顺序 / 随机 / 错题重刷，正确率统计，进步看得见
- **面试复盘**：面完记一笔——被问最多的问题、答得如何、下次怎么改进，越面越好
