============================================================
一、产品概况
============================================================

「简历智诊」是一款面向求职者（尤其是应届毕业生与校招人群）的求职进度管理与面试准备工具，
核心功能：

  1. 求职看板：记录投递进度（公司/岗位/渠道/状态/日程），漏斗统计，面试日程提醒
  2. 简历自查清单：5 大维度 24 项预设检查项，逐项确认后规则加权打分（预设规则，非 AI 生成）
  3. 岗位比对（JD 关键词比对）：粘贴简历与 JD，本地词库匹配，计算关键词覆盖率
  4. 简历解析：粘贴简历文本，按预设规则提取联系方式/教育/技能/经历（规则提取，非 AI 生成）
  5. 面试题库：100+ 道预设高频题（行为面/后端/前端/算法/HR），可搜索、可收藏
  6. 面试练习室：抽题 + 计时 + 文字作答 + 对照预设参考答案 + 自评打分
  7. 刷题模式：顺序/随机/错题重刷，正确率统计
  8. 面试复盘：结构化模板记录面试情况
  9. 求职 Checklist / 学习路径 / 自我介绍模板 / 校招倒计时 / 数据统计 / Offer 对比 /
     待办清单 / 投递时间线 / 数据备份与恢复 / 历史记录

产品定位：个人效率工具（记录/清单/进度/练习）。不提供职位信息、不连接用人单位、
不提供招聘撮合或简历代投服务。所有内容由用户自行录入，仅本人可见。

关键说明：本小程序**不调用任何生成式 AI / 大模型接口**。所有检查项、比对结果、
题库内容、解析规则均为开发时预设的静态规则库与本地计算，不产生任何 AI 生成内容。

二、收集的信息与具体用途
============================================================

本小程序严格遵循「最小必要」原则，仅在使用核心功能所需时处理下列信息：

【1】用户主动录入/粘贴的内容（简历文本、JD 文本、投递记录、复盘内容等）
    用途：作为「简历自查」「岗位比对」「简历解析」「求职看板」等功能的输入内容
    获取方式：用户在页面中主动输入或粘贴
    存储位置：**默认仅存本机**（微信本地存储 wx.setStorageSync），不上传服务器
    留存时间：用户可随时在「我的」页删除全部历史数据；删除即清除

【2】简历附件文件（PDF / Word(.docx) / TXT）
    用途：从微信聊天记录中选择简历文件，经云端解析为纯文本后回填页面供检查/比对
    获取方式：用户点击「从文件导入」按钮，从微信聊天记录中选择文件
    涉及的接口：wx.chooseMessageFile（从微信选择文件）
    安全处理：文件仅作为解析**中转**：上传至云开发存储后由云函数 parse-resume
              解析为纯文本，云函数在解析完成后（finally 分支）**立即删除云端文件**，
              不做任何留存；业务侧只接收解析后的文本，不保存文件本身。
    留存时间：解析完成后云端文件即时删除；解析出的文本随【1】仅存本机

【3】剪贴板
    用途：用户在「复制自查报告 / 比对结果 / 解析摘要 / 错误信息」等按钮上
          主动点击时，将目标文本写入剪贴板，方便粘贴到其他应用
    获取方式：用户主动点击「复制」按钮
    涉及的接口：wx.setClipboardData（仅写入，用户主动触发）
    行为承诺：本小程序**不主动读取**剪贴板内容，仅在用户点击复制按钮时写入文本

【4】日程提醒时间（可选，默认不开启）
    用途：看板中记录的笔试/面试日程，若用户**主动开启「云提醒」**，
          仅将日程的时间字段上传云端，用于触发微信订阅消息通知
    获取方式：用户在日程上主动开启提醒
    存储与上传：默认本地；仅在用户开启提醒后才上传**时间字段**（不包含公司、
              岗位等敏感信息），且仅用于发送订阅消息
    涉及的接口：wx.requestSubscribeMessage（微信订阅消息，需用户主动授权）
    留存时间：取消提醒或删除该记录时清除

【5】设备信息（系统类型、基础库版本等）
    用途：服务端错误诊断与兼容性适配
    获取方式：微信平台自动提供（用于匿名登录与云函数调用）
    留存时间：服务端日志默认 7 天自动清理

关于登录：小程序使用微信匿名登录（openid，由微信平台生成，不含手机号、昵称、
头像等个人信息），仅用于云函数调用隔离与文件上传目录区分，不收集用户身份资料。
本小程序**不获取用户昵称、头像、手机号**。

============================================================
三、不收集的信息（与隐私指引勾选项保持一致）
============================================================

本小程序明确不收集以下信息：

  - 手机号、通讯录、地理位置（精确/粗略位置）
  - 用户昵称、头像、真实姓名、身份证号、银行卡信息
  - 摄像头拍摄内容
  - 麦克风采集的音频（v1.2 起已移除录音能力，练习室改为文字作答）
  - 蓝牙、微信好友关系、微信运动数据
  - 收货地址、发票信息
  - 任何形式的用户行为画像与广告追踪数据

【静态声明说明】小程序引用的 UI 组件库 TDesign（vendor 化内置）部分组件源码
中含有 wx.chooseImage 等接口声明，但**本产品未提供任何「选择图片/相册/拍照」
相关功能入口，未实际调用该接口**；隐私指引中亦未声明相册权限。

============================================================
四、数据生命周期
============================================================

【本地存储数据（简历文本、自查/比对/练习记录、投递记录等）】
  - 存储：微信本地存储（仅存本机，默认不上传）
  - 留存：用户可随时在「我的」页一键删除全部历史数据
  - 删除后：本地立即清除，不做备份留存

【上传的简历附件】
  - 仅用于即时解析，解析完成后云端文件立即删除
  - 解析出的纯文本只作为功能输入暂存本地，随本地数据一并可删

【订阅消息日程】
  - 仅在用户主动开启后上传时间字段；取消提醒或删除记录即清除

【设备日志】
  - 仅服务端保留用于错误诊断，默认 7 天自动清理

五、第三方 SDK / 插件
============================================================

本小程序使用的 SDK 全部由微信平台或腾讯官方提供，且在隐私指引中已披露：

  1. 微信云开发（含云函数、云数据库、云存储）
     - 提供方：腾讯云
     - 用途：简历附件解析中转（parse-resume）、匿名登录（login）、
            可选日程提醒推送（reminder）
     - 说明：本小程序**不使用云开发提供的任何生成式 AI 能力**，
            云函数中无任何大模型调用
     - 隐私保障：腾讯云微信云开发环境遵循《腾讯云隐私政策》

  2. TDesign 微信小程序组件库
     - 提供方：腾讯 TDesign 团队
     - 用途：UI 组件
     - 接入方式：vendor 化内置引入（不构建、不联网加载第三方资源）

本小程序**不接入**任何第三方广告 SDK、统计 SDK、推送 SDK、分析 SDK、地图 SDK。

============================================================
六、用户权利
============================================================

本小程序保障用户对个人信息的以下权利：

  - 【查看】可在「我的」→「历史记录」查看全部自查/比对/练习/看板记录
  - 【复制】可在结果页主动点击「复制」按钮将结果复制到剪贴板
  - 【删除】可在「我的」页一键删除全部本地数据，操作不可恢复
  - 【撤回授权】可通过「我的」→「用户隐私保护指引」撤回授权；撤回后
      功能仅保留纯本地记录能力（不上传任何内容）
  - 【导出备份】可在「我的」→「数据备份与恢复」导出全部数据 JSON 备份，
      用于换机恢复；导出的数据由用户自行保管

八、合规承诺
============================================================

  1. 严格遵循「最小必要」原则处理信息，仅处理用户主动输入的内容
  2. 数据默认仅存本机，仅本人可见，无公开分享页、无社区传播
  3. 简历附件仅用于即时解析，解析后立即删除云端文件，不做留存
  4. **不调用任何生成式 AI / 大模型接口**；所有检查项、比对结果、题库内容、
     解析结果均为预设规则库与本地计算，不产生 AI 生成内容
  5. 不进行任何形式的用户行为画像与个性化广告推送
  6. 不向第三方提供、出售、交换用户数据
  7. 本小程序为个人求职记录工具，不提供职位信息、不连接用人单位、
     不提供招聘撮合或简历代投服务
